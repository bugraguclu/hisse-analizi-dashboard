# iPhone analiz ekranları: önce / sonra

`iphone-once-sonra.html` dosyasını tarayıcıda açın. Tarama, Hisse analizi ve Makro düğmeleriyle ekranlar arasında geçiş yapılabilir. Hisse analizinde Genel, Teknik, Temel ve Analiz görünümleri karşılaştırılabilir.

- **Önce:** `ea3bc76` sürümündeki mobil ekran kodunun görsel canlandırmasıdır; uygulamadan alınmış ekran görüntüsü değildir. Fiyat alanı örnek değerle doldurulmuştur.
- **Sonra:** Tamamlanacak mobil analiz ekranları için tasarım önerisidir. Bu dosya, mobil uygulamadaki özelliklerin uygulanmış olduğunu göstermez.
- Bütün fiyatlar, oranlar, finansal tablolar ve grafik serileri temsilîdir. Canlı veri isteği yapılmaz.
- Filtreleme, sıralama, sekme geçişi ve gösterge seçimi yalnızca karşılaştırma içindeki örnek verileri değiştirir.

PNG karşılaştırmaları: `tarama-once-sonra.png`, `teknik-once-sonra.png`, `temel-once-sonra.png`, `makro-once-sonra.png`.

23 Kasım 2026 tarihinde hazırlanmıştır. Bu tasarım çalışması web yayını, TestFlight dağıtımı veya mobil ekranların tamamlanması kapsamında değildir.

Canlı paylaşım yolu: `/onizleme/iphone-once-sonra.html`. Statik yayın dosyası `dashboard/public/onizleme/` altında yer alır; uygulama dışı görüntüleme kabuğu çıkarılmıştır.
